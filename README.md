# Spike Flutter Customer

Native Flutter customer application for Spike marketplace (Android + iOS), no WebView.

## Reference
- Customer UI: `aymanjameel60/spikrfront`
- Backend: `aymanjameel60/spike2`
- Production API: `https://spike2.aymanjameel60.deno.net/api/v1`

This repository continues the previously built Phase 2 baseline and will be developed incrementally against the production backend and latest customer UI.
